# ResumeIQ

## Project Summary

ResumeIQ is an AI-powered resume analysis and job matching application developed using Python. The application automatically extracts information from resumes, analyzes job descriptions, compares candidate skills with job requirements, and generates an intelligent match score with detailed feedback.

ResumeIQ combines document processing, AI agents, resume parsing, job description analysis, and LLM-powered reasoning to help recruiters and job seekers evaluate resume compatibility more efficiently.

---

# ResumeIQ Problem Statement

Recruiters often spend significant time manually reviewing resumes and comparing them with job descriptions. This process becomes difficult when handling large numbers of applications and maintaining consistent evaluation criteria.

ResumeIQ automates this workflow by extracting resume information, understanding job requirements, comparing candidate profiles with job descriptions, and generating an AI-assisted compatibility score.

# ResumeIQ Resume Analysis Workflow

The ResumeIQ resume analysis process follows these steps:

1. User uploads a resume.
2. Resume text is extracted.
3. AI agent identifies important candidate information.
4. Structured resume data is generated.
5. Resume information is prepared for comparison.

---

# ResumeIQ Job Description Analysis Workflow

The ResumeIQ job analysis process follows these steps:

1. User provides a job description.
2. AI extracts required skills.
3. Required qualifications are identified.
4. Job requirements are structured.
5. Job profile is prepared for matching.
